# SUPERMARKET_SALES_ANALYSIS
## Project Overview
This project demonstrates customer purchasing behavior, product performance, and sales trends using the Supermarket Sales dataset. The analysis focuses on identifying revenue-driving branches, customer spending patterns, preferred payment methods, and high-performing product categories through data cleaning, exploration, and SQL-based business analysis.

## Tools & Technologies
- Python
- SQL
- Microsoft Word

## Workflow
1. Data Exploration, Data Cleaning and preprocessing 
using Python (Google colab)
2. SQL for Data Analysis and solving Business Problems using MySQL workbench
3. Documentation of findings and suggestions in Word  

## Key Insights
- Branch A generated the highest revenue  
- Fashion Accessories and Home & Lifestyle contributed major sales  
- Customers preferred Credit Card and E-wallet payments  
- Spending patterns varied across gender and customer types  

## Files Included
- `supermarket_sales.csv` → Dataset  
- `Supermarket sales.ipynb` → Python data cleaning & exploration  
- `supermarket project.sql` → SQL analysis queries  
- `SUPERMARKET SALES.pdf` → Findings and suggestions report  

## Conclusion
The project helped identify customer behavior, product trends, and revenue-driving factors to support better business decisions.
